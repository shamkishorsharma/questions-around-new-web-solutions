## Which Link To Use

- Setup / activation: Onboard Web Attribution, Add a website app, Web SDK.
- URL parameters / source issues: Traffic source resolution, Landing page URL attribution parameters.
- CUID / cross-device / web-to-mobile questions: User-based cross-platform attribution, Web SDK `setCustomerUserId`, S2S user identification.
- S2S-only implementation: S2S API, S2S user identification, request body, extract web cookie.
- Raw data / customer reporting: Data Locker export article.
- Partner optimization postbacks: the partner-specific web campaign article, plus Web Attribution Overview if needed.

Verify exact article wording with live browsing when the answer depends on a narrow implementation detail or may have changed.
